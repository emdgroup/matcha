class matcha.torch.encoders.cnn.CNN(num_characters: int, embedding_dim: int, hidden_dim: int, kernel_dims: list[int], num_heads: int, activation: str, dropout: float)[source]

Bases: matcha.torch.encoders.base_encoder.BaseEncoder, lightning.pytorch.core.mixins.HyperparametersMixin

1D convolution neural network (CNN) encoder for modelling chemical language representations. After processing the input sequence, self attention is used to compute a global representation of the molecule by making the [cls] token attend to each other position in the string. It inherits from lightning.pytorch.core.mixins for saving its hyperparameters, and from BaseEncoder to be consistent with other encoders. References: - https://arxiv.org/abs/2407.12152 - https://pubs.rsc.org/en/content/articlehtml/2023/dd/d2dd00099g

It is intended to be used inside a BaseClassicModel instance. Check the docs of matcha.torch.models.classic.CNNModel for further details.

Parameters:

  • num_characters (int) – total number of unique tokens in the dataset’s dictionary

  • embedding_dim (int) – number of token embedding features

  • hidden_dims (list[int]) – number of hidden token dimensionality across each convolutional layer

  • kernel_dims (list[int]) – kernel sizes for each convolutional layer

  • num_heads (int) – number of self attention heads, must divide hidden_dims evenly

  • activation (str) – activation function to use throughout all layers

  • dropout (float) – dropout noise level
