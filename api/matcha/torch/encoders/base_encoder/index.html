Bases: lightning.LightningModule, abc.ABC

Abstract base class for all encoders.

Defines the interface that all encoder subclasses must implement. Enforces the presence of a forward() method that maps featurized molecular inputs to fixed-size embedding tensors.

Not meant to be instantiated directly; use a concrete subclass such as GIN, GPS, CNN, etc.

abstractmethod forward(x: object) → torch.Tensor[source]

This method needs to convert the batched output from one of the featurizers into a torch.Tensor of shape (batch_size, K), which can then be processed by a MLP-like architecture for prediction.

Parameters:

x (object) – The batched output from any featurizer. Depending on the featurizer, it can be different things, e.g. torch.Tensor, list, …

Return torch.Tensor:

a tensor of shape (batch_size, K), corresponding to the learned embeddings for the batch_size molecules.
