1D convolution neural network (CNN) encoder for modelling chemical language representations. After processing the input sequence, self attention is used to compute a global representation of the molecule by making the [cls] token attend to each other position in the string. It inherits from lightning.pytorch.core.mixins for saving its hyperparameters, and from BaseEncoder to be consistent with other encoders. References: - https://arxiv.org/abs/2407.12152 - https://pubs.rsc.org/en/content/articlehtml/2023/dd/d2dd00099g

It is intended to be used inside a BaseClassicModel instance. Check the docs of matcha.torch.models.classic.CNNModel for further details.

Parameters:

  • embedding_dim (int) – number of token embedding features

  • hidden_dims (list[int]) – number of hidden token dimensionality across each convolutional layer

  • kernel_dims (list[int]) – kernel sizes for each convolutional layer

  • num_heads (int) – number of self attention heads, must divide hidden_dims evenly

  • activation (str) – activation function to use throughout all layers

  • dropout (float) – dropout noise level

Bases: matcha.torch.encoders.base_graph_encoder.BaseGraphEncoder, lightning.pytorch.core.mixins.HyperparametersMixin

E(n) Equivariant Graph Neural Network encoder.

This class performs message passing on molecular conformers using E(n) equivariant convolutions, updates the atom representations according to relative atomic positions and bond information, then returns a molecular embedding for property prediction.

Uses the EGNN_Sparse layer for efficient message passing on sparse graphs.

It inherits from BaseGraphEncoder for common graph encoding routines (e.g. jk-related routines) and from lightning.pytorch.core.mixins for saving its hyperparameters.

References: - https://arxiv.org/abs/2102.09844 (E(n) Equivariant Graph Neural Networks)

It is intended to be used inside a BaseClassicModel instance.

Parameters:

  • num_layers (int) – number of message passing layers

  • atom_input_dim (int) – number of input atom features from GraphFeaturizer

  • bond_input_dim (int) – number of input bond features from GraphFeaturizer

  • hidden_features (int) – number of hidden features in message passing layers

  • m_dim (int) – dimension of message hidden layer in EGNN

  • fourier_features (int) – number of Fourier features for distance encoding

  • soft_edge (bool) – whether to use soft edge attention

  • norm_feats (bool) – whether to normalize node features

  • norm_coors (bool) – whether to normalize coordinates

  • update_coors (bool) – whether to update coordinates during message passing

  • activation (str) – activation function to be used in projection layers

  • dropout (float) – dropout noise level for projection layers

  • jk (str) – jumping knowledge strategy to use when returning molecular representations after forward pass

  • readout (str) – readout function to aggregate all atom representations

Bases: matcha.torch.encoders.base_graph_encoder.BaseGraphEncoder, lightning.pytorch.core.mixins.HyperparametersMixin

3D-aware General, Powerful, Scalable (GPS) Graph Transformer encoder.

Combines local message passing with global self-attention for learning molecular representations, using 3D coordinate information for spatial encoding. Uses PyTorch Geometric for all graph operations.

This encoder extends GPS by using 3D Gaussian Basis Kernel spatial encoding based on actual 3D coordinates instead of graph-based shortest path distances.

It inherits from BaseGraphEncoder for common graph encoding routines (e.g. jk-related routines) and from lightning.pytorch.core.mixins for saving its hyperparameters.

References: - https://arxiv.org/abs/2210.01765 (Uni-Mol: One Transformer Can Understand Both 2D & 3D Molecular Data) - https://arxiv.org/abs/2205.12454 (GPS) - https://arxiv.org/abs/2102.09844 (EGNN)

It is intended to be used inside a BaseClassicModel instance.

Parameters:

  • num_layers (int) – number of message passing layers

  • atom_input_dim (int) – number of input atom features from GraphFeaturizer

  • bond_input_dim (int) – number of input bond features from GraphFeaturizer

  • atom_hidden_dim (int) – number of hidden atom (and bond) features in message passing layers

  • num_heads (int) – number of attention heads, must divide atom_hidden_dim evenly

  • expansion_k (int) – expansion factor for the feed-forward network in GPSBlock

  • num_kernels (int) – number of Gaussian Basis Kernels for 3D spatial encoding

  • activation (str) – activation function to be used in all layers

  • dropout (float) – dropout noise level

  • norm (str | None) – which norm to use inside LnBnDr layers

  • jk (str) – jumping knowledge strategy to use when returning molecular representations after forward pass

  • readout (str) – readout function to aggregate all atom representations

Graph Transformer encoder using stacked GTConv layers with distance-biased attention.

A graph transformer architecture that uses multi-head self-attention with edge features and shortest-path distance encoding as attention bias.

Architecture: atom_projection, bond_projection → GTConv stack (with distance bias) → readout

It inherits from BaseGraphEncoder for common graph encoding routines (e.g. jk-related routines) and from lightning.pytorch.core.mixins for saving its hyperparameters.

References: - Graph Transformer: https://arxiv.org/abs/2012.09699 - GPS: https://arxiv.org/abs/2205.12454

It is intended to be used inside a BaseClassicModel instance.

Parameters:

  • num_layers (int) – number of GTConv layers

  • atom_input_dim (int) – number of input atom features from GraphFeaturizer

  • bond_input_dim (int) – number of input bond features from GraphFeaturizer

  • atom_hidden_dim (int) – hidden dimension for atom features in GTConv layers

  • num_heads (int) – number of attention heads, must divide atom_hidden_dim evenly

  • expansion_k (int) – expansion factor for the feed-forward network in GTConv layers

  • distance_k (int | None) – maximum shortest-path distance for spatial encoding, None to disable

  • activation (str) – activation function to be used in all layers

  • dropout (float) – dropout noise level

  • jk (str) – jumping knowledge strategy (‘last’, ‘concat’, ‘max’, ‘sum’)

  • readout (str) – readout function to aggregate atom representations
