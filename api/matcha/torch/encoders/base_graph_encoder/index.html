Base class for all graph encoders. It is not meant to be instantiated directly, but rather to be used as a parent class for each featurizer. Subclasses from BaseEncoder to ensure that a :method:`forward` method is present in children classes. The class is just used to automate some tedious processes related to PyTorch Geometric (see :method:`process_graph_batch`), handle different readout functions and jumping knowledge settings.
