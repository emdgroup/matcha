Base class for all graph encoders. It is not meant to be instantiated directly, but rather to be used as a parent class for each featurizer. Subclasses from BaseEncoder to ensure that a :method:`forward` method is present in children classes. The class is just used to automate some tedious processes related to PyTorch Geometric (see :method:`process_graph_batch`), handle different readout functions and jumping knowledge settings.

Concrete subclasses implement forward_nodes_per_layer() to produce per-layer node embeddings; the shared forward() template method then combines them via the configured jumping-knowledge strategy and the readout to produce a graph-level embedding. This structural contract is what prevents architecture drift between classic and pretraining models — both consume the same encoder, and pretraining hooks read the per-layer output of the canonical encoder rather than re-implementing the layer stack.

abstractmethod forward_nodes_per_layer(graph: torch_geometric.data.Batch) → tuple[list[torch.Tensor], torch_geometric.data.Batch][source]

Run message passing and return one node-feature tensor per layer.

Concrete graph encoders should implement this to expose the intermediate node representations produced by every message-passing layer. It is the single hook consumed by both the classic path (via forward()) and the pretraining path (via BaseGraphPretrainingModel), so the same layer stack is guaranteed to drive both.

The default implementation raises NotImplementedError so that encoders which have not yet migrated to the shared contract (rolled out per-architecture across the issue #24 stages) still work on the classic path but fail loudly if the pretraining path is wired against them. Once every BaseGraphEncoder subclass implements this method, the base can be tightened to @abstractmethod.

Parameters:

graph (Batch) – Batched PyG graph from the dataloader.

Returns:

A tuple of (all_atom_feats, g) where all_atom_feats is a list of length num_layers containing node features of shape [num_nodes, atom_hidden_dim], and g is the (possibly modified) PyG Batch used for the readout.

forward(graph: torch_geometric.data.Batch) → torch.Tensor[source]

Convert a batched PyG graph into a [batch_size, fp_dim] embedding.

Template method that delegates the layer loop to forward_nodes_per_layer(), combines the per-layer node features via the configured jumping-knowledge strategy, and applies the readout. Subclasses that have migrated to the shared contract should not override this method — override forward_nodes_per_layer() instead. Legacy subclasses may still override forward() directly until they migrate.
