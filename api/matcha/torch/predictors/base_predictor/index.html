class matcha.torch.predictors.base_predictor.BasePredictor[source]

Bases: torch.nn.Module

Base class for all predictors.

Not meant to be instantiated directly; subclass this and define self.layers (the hidden body) and self.prediction_head (the final linear mapping). The standard forward() and encode() methods then work out of the box.

property latent_dim: int
