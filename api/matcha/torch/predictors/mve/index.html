Bases: matcha.torch.predictors.base_predictor.BasePredictor

Predictor head for Mean-Variance Estimation (MVE) uncertainty.

Reuses the MLP-style LnBnDr hidden body and splits the prediction into two parallel torch.nn.Linear heads: one producing the per-endpoint means and one producing the per-endpoint log-variances. Their outputs are concatenated along the feature axis, so forward() returns a tensor of shape (batch, 2 * num_endpoints) with means in the first num_endpoints columns and log-variances in the next num_endpoints columns.

Predicting the log-variance (rather than the variance) keeps the head unconstrained and numerically stable; downstream β-NLL losses (matcha.nn.losses.BetaNLLLoss, matcha.nn.losses.BoundedBetaNLLLoss) exponentiate it internally and clamp for stability.

Intended to be used inside a BaseClassicModel instance whenever uncertainty == "mve".

Parameters:

  • input_dim (int) – Input feature dimensionality.

  • hidden_dims (list[int] or None) – Shape of the shared hidden body. None skips it.

  • num_endpoints (int) – Number of prediction endpoints. The head output width is 2 * num_endpoints.

  • dropout (float) – Dropout rate applied inside each LnBnDr block.

  • activation (str) – Activation name resolved via matcha.nn.activations.ActivationRegistry.

  • norm (str or None) – Normalization name resolved via matcha.nn.layers.LayerRegistry, or None.
