class matcha.torch.predictors.mlp.MLP(input_dim: int, hidden_dims: list[int] | None, task_head_dims: list[int] | None, num_endpoints: int, dropout: float, activation: str, norm: str | None)[source]

Bases: matcha.torch.predictors.base_predictor.BasePredictor

Multi Layer Perceptron (MLP) utility class. It inherits from BasePredictor for common routines (e.g. forward pass).

It is intended to be used inside a BaseClassicModel instance. Check the docs of matcha.torch.models.classic.MLPModel for further details.

Parameters:

  • input_dim (int) – input feature dimensionality

  • hidden_dims (list[int]) – shape of shared hidden MLP layers in the predictor across all endpoints

  • task_head_dims (list[int]) – shape of the MLP layers dedicated to each task independently, defaults to None (skipped)

  • activation (str) – activation function to use across the network

  • dropout (float) – dropout rate between all layers

  • num_endpoints (int) – number of endpoints (if multitasking) or classes, (if classification) to predict

  • batchnorm (bool) – whether to use batchnorm across all layers
