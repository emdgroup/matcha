class matcha.torch.models.classic.base_classic_model.BaseClassicModel(additional_mol_features_dim: int = 0)[source]

Bases: matcha.torch.models.mixin.ModelMixin, abc.ABC

Base class for all classic models. It is not meant to be instantiated directly, but rather to be used as a parent class for each classic model. It should encompass all basic routines needed for training and inference, therefore child classes only need to define what are the encoder and predictor attributes.
