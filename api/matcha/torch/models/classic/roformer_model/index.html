RoFormer-based transformer for molecular property prediction from chemical language (e.g. SMILES via augmented input strings).

Uses rotary position embeddings (RoPE) for relative position encoding in self-attention. Inherits from BaseClassicModel for common training/prediction routines and from HyperparametersMixin for saving hyperparameters.

References:

  • Su et al., RoFormer: Enhanced Transformer with Rotary Position Embedding (https://arxiv.org/abs/2106.09553)

Example usage:

model = RoFormerModel(enc_num_characters=n_tokens)
trainer = L.Trainer(max_epochs=50)
trainer.fit(model=model, train_dataloaders=train_dataloader)
Parameters:

  • enc_num_characters (int) – vocabulary size (unique tokens), required

  • enc_hidden_dim (int) – token embedding and hidden dimensionality, defaults to 256

  • enc_expansion_dim (int) – feed-forward expansion dimensionality, defaults to 1024

  • enc_num_heads (int) – number of self-attention heads, defaults to 4

  • enc_num_layers (int) – number of transformer blocks, defaults to 2

  • enc_attention_dropout (float) – dropout in attention computation, defaults to 0.1

  • enc_hidden_dropout (float) – dropout in feed-forward layers, defaults to 0.1

  • additional_mol_features_dim (int) – dimensionality of extra molecular features concatenated to encoder output, defaults to 0

  • pred_hidden_dims (list[int]) – hidden layer sizes in the MLP predictor, defaults to [512, 256]

  • pred_task_head_dims (list[int] | None) – per-task head dimensions, defaults to None

  • pred_activation (str) – activation in the predictor, defaults to ‘swish’

  • pred_dropout (float) – dropout rate in the predictor, defaults to 0.2

  • num_endpoints (int) – number of prediction targets, defaults to 1

  • loss_fn (str) – loss function name, defaults to ‘mse’

  • loss_args (dict) – additional loss function arguments, defaults to {}

  • optimizer (str) – optimizer name, defaults to ‘adam’

  • optimizer_args (dict) – additional optimizer arguments, defaults to {‘lr’: 1e-3}

  • scheduler (str) – learning rate scheduler name, defaults to ‘cosine_annealing’

  • scheduler_args (dict) – additional scheduler arguments, defaults to {‘min_lr’: 1e-6, ‘total_steps’: 50}
