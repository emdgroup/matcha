AttentiveFP model for molecular property prediction.

Uses graph attention with a gated readout mechanism to learn molecular representations. Inherits from BaseClassicModel for common training/prediction routines and from HyperparametersMixin for saving hyperparameters.

Reference: Xiong et al., Pushing the Boundaries of Molecular Representation for Drug Discovery with the Graph Attention Mechanism (https://doi.org/10.1021/acs.jmedchem.9b00959)

Example usage:

model = AttentiveFPModel()
trainer = L.Trainer(max_epochs=50)
trainer.fit(model=model, train_dataloaders=train_dataloader)
Parameters:

  • additional_mol_features_dim (int) – dimensionality of extra molecular features concatenated to encoder output, defaults to 0

  • enc_num_layers (int) – number of attention layers, defaults to 2

  • enc_atom_input_dim (int) – input atom feature dimensionality, defaults to 44

  • enc_bond_input_dim (int) – input bond feature dimensionality, defaults to 14

  • enc_atom_hidden_dim (int) – hidden atom feature dimensionality, defaults to 300

  • enc_jk (str) – jumping knowledge strategy, defaults to ‘concat’

  • enc_readout (str) – graph-level readout strategy, defaults to ‘vpa’

  • enc_dropout (float) – dropout rate in the encoder, defaults to 0.2

  • enc_laplacian_k (int) – Laplacian positional encoding dimension, defaults to 10

  • enc_rwse_k (int) – random-walk structural encoding dimension, defaults to 20

  • enc_elstatic_k (int) – electrostatic encoding dimension, defaults to 0

  • enc_distmat_k (int) – distance matrix encoding dimension, defaults to 0

  • enc_rrwp_k (int) – relative random-walk probabilities dimension, defaults to 0

  • pred_hidden_dims (list[int]) – hidden layer sizes in the MLP predictor, defaults to [512, 256]

  • pred_task_head_dims (list[int] | None) – per-task head dimensions, defaults to None

  • pred_activation (str) – activation in the predictor, defaults to ‘swish’

  • pred_dropout (float) – dropout rate in the predictor, defaults to 0.2

  • num_endpoints (int) – number of prediction targets, defaults to 1

  • loss_fn (str) – loss function name, defaults to ‘mse’

  • loss_args (dict) – additional loss function arguments, defaults to {}

  • optimizer (str) – optimizer name, defaults to ‘adam’

  • optimizer_args (dict) – additional optimizer arguments, defaults to {‘lr’: 1e-3}

  • scheduler (str) – learning rate scheduler name, defaults to ‘cosine_annealing’

  • scheduler_args (dict) – additional scheduler arguments, defaults to {‘min_lr’: 1e-6, ‘total_steps’: 50}

Chemprop Directed Message Passing Neural Network (D-MPNN) for molecular property prediction.

Wraps the Chemprop MPNN implementation with matcha’s registry and hyperparameter management. Unlike other classic models, this class inherits directly from chemprop.models.model.MPNN and uses Chemprop’s built-in scheduler and optimizer by default.

Reference: Yang et al., Analyzing Learned Molecular Representations for Property Prediction (https://arxiv.org/abs/1904.01561)

Example usage:

model = ChempropModel(num_endpoints=1)
trainer = L.Trainer(max_epochs=50)
trainer.fit(model=model, train_dataloaders=train_dataloader)
Parameters:

  • enc_atom_hidden_dim (int) – hidden dimensionality of bond message passing, defaults to 300

  • enc_num_layers (int) – depth of message passing, defaults to 3

  • enc_dropout (float) – dropout in message-passing layers, defaults to 0.2

  • enc_activation (str) – activation function in the encoder, defaults to ‘relu’

  • enc_readout (str) – aggregation strategy (‘norm’, ‘mean’, ‘sum’, ‘attentive’), defaults to ‘norm’

  • additional_mol_features_dim (int) – dimensionality of extra molecular features concatenated to the learned fingerprint, defaults to 0

  • pred_hidden_dim (int) – hidden size of feed-forward predictor layers, defaults to 300

  • pred_num_layers (int) – number of feed-forward predictor layers, defaults to 2

  • pred_dropout (float) – dropout in predictor layers, defaults to 0.2

  • pred_activation (str) – activation in predictor layers, defaults to ‘relu’

  • num_endpoints (int) – number of prediction targets, defaults to 1

  • loss_fn (str) – loss function name (‘mse’, ‘bce’, ‘ce’), defaults to ‘mse’

  • optimizer (str) – optimizer name, defaults to ‘chemprop’

  • optimizer_args (dict) – optimizer arguments, defaults to {‘lr’: 1e-3}

  • scheduler (str) – scheduler name, defaults to ‘chemprop’

  • scheduler_args (dict) – scheduler arguments, defaults to {‘warmup_epochs’: 5, ‘max_lr’: 1e-2, ‘final_lr’: 1e-5}

Recurrent Neural Network (RNN) for molecular property prediction from chemical language (e.g. SMILES via augmented input strings).

Supports GRU and LSTM variants with optional bidirectional encoding and self-attention pooling. Inherits from BaseClassicModel for common training/prediction routines and from HyperparametersMixin for saving hyperparameters.

References:

  • https://arxiv.org/abs/2407.12152

  • https://www.sciencedirect.com/science/article/pii/S2667318521000143

Example usage:

model = RNNModel(enc_num_characters=n_tokens)
trainer = L.Trainer(max_epochs=50)
trainer.fit(model=model, train_dataloaders=train_dataloader)
Parameters:

  • additional_mol_features_dim (int) – dimensionality of extra molecular features concatenated to encoder output, defaults to 0

  • enc_num_layers (int) – number of recurrent layers, defaults to 2

  • enc_num_characters (int) – vocabulary size (unique tokens), defaults to 400

  • enc_embedding_dim (int) – token embedding dimensionality, defaults to 100

  • enc_rnn_type (str) – RNN variant to use (‘gru’ or ‘lstm’), defaults to ‘gru’

  • enc_hidden_dim (int) – hidden size per recurrent layer, defaults to 256

  • enc_bidirectional (bool) – whether to use bidirectional encoding, defaults to True

  • enc_num_heads (int) – number of self-attention heads for pooling, defaults to 4

  • enc_dropout (float) – dropout rate in the encoder, defaults to 0.2

  • pred_hidden_dims (list[int]) – hidden layer sizes in the MLP predictor, defaults to [512, 256]

  • pred_task_head_dims (list[int] | None) – per-task head dimensions, defaults to None

  • pred_activation (str) – activation in the predictor, defaults to ‘swish’

  • pred_dropout (float) – dropout rate in the predictor, defaults to 0.2

  • num_endpoints (int) – number of prediction targets, defaults to 1

  • loss_fn (str) – loss function name, defaults to ‘mse’

  • loss_args (dict) – additional loss function arguments, defaults to {}

  • optimizer (str) – optimizer name, defaults to ‘adam’

  • optimizer_args (dict) – additional optimizer arguments, defaults to {‘lr’: 1e-3}

  • scheduler (str) – learning rate scheduler name, defaults to ‘cosine_annealing’

  • scheduler_args (dict) – additional scheduler arguments, defaults to {‘min_lr’: 1e-6, ‘total_steps’: 50}
