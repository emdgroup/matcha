Self-Normalizing Neural Network (SNN) to predict molecular properties from molecular descriptors and fingerprints. SNNs use SELU activations and AlphaDropout to maintain self-normalizing properties, which can help with training deep networks without batch normalization.

It inherits from BaseClassicModel for common training and predicting routines (e.g. forward pass) and from lightning.pytorch.core.mixins for saving its hyperparameters.

References: - Self-Normalizing Neural Networks: https://arxiv.org/abs/1706.02515

Example usage:

Parameters:

  • hidden_dims (list[int]) – shape of hidden SNN layers in the predictor, defaults to [512, 512, 128]

  • dropout (float) – dropout rate across the predictor (uses AlphaDropout), defaults to 0.05

  • num_endpoints (int) – number of endpoints (if multitasking) or classes, (if classification) to predict, defaults to 1

  • deep_lasso_weight (float) – weight for the deep lasso regularization, defaults to 0.1

  • loss_fn (str) – loss function to optimize, defaults to ‘mse’

  • loss_args (dict) – additional arguments for the loss function (e.g. for focal loss), defaults to {}

  • optimizer (str) – optimizer to use while training, defaults to ‘adam’

  • optimizer_args (dict) – additional arguments for the optimizer, defaults to {‘lr’: 1e-3}

  • scheduler (str) – scheduler to change the learning rate during training, defaults to ‘cosine_annealing’

  • scheduler_args (dict) – additional arguments for the scheduler, defaults to {‘min_lr’: 1e-6, ‘total_steps’: 50}

  • num_parallel (int) – number of parallel heads in MultiLn layers, defaults to 8
