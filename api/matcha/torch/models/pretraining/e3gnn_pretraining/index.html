matcha.torch.models.pretraining.e3gnn_pretraining

E3GNN pretraining model for supervised multi-task learning on 3D graphs.

Jointly predicts user-provided atom-level and molecule-level labels via a shared E(n)-equivariant encoder with separate prediction heads. Consumes batches produced by Graph3DPretrainingDataModule — 3D coordinates ride on graph.pos and are read by the encoder’s per-layer hook.

E3GNN model for pretraining with node-level and graph-level predictions.

Mirrors GINPretraining — a single equivariant encoder forward pass produces both:

  • Node-level predictions via a dedicated node MLP head

  • Graph-level predictions via readout + graph MLP head

Both prediction targets are user-provided labels; the model does not reconstruct its own input atom features. Node-level targets are typically computed atom properties (partial charges, SASA, electronegativity, …); graph-level targets are molecular descriptors (logP, MW, …).

3D coordinates are transported to the encoder on graph.pos. The encoder’s E3GNN.forward_nodes_per_layer() reads them from there.

Example usage:

model = E3GNNPretraining(
    num_node_targets=3,    # e.g., partial charge, SASA, electronegativity
    num_graph_targets=2,   # e.g., logP, molecular weight
)

trainer = L.Trainer(max_epochs=50)
trainer.fit(model=model, train_dataloaders=train_dataloader)
