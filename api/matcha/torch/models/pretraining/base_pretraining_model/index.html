Bases: lightning.LightningModule, abc.ABC

Base class for all pretraining models.

This class provides common functionality for pretraining models, including loss function parsing, optimizer/scheduler configuration, and training/validation step logic.

Subclasses must implement:

  • forward(): Returns predictions for the pretraining task

  • encode(): Returns learned representations
