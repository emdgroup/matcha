RoFormer encoder variant that returns per-token embeddings instead of aggregating to a single CLS token representation.

This encoder is designed for Masked Language Modeling (MLM) tasks where predictions need to be made for each token position.

RoFormer model variant for Masked Language Modeling (MLM).

This model returns per-token predictions for use in MLM self-supervised learning setups. Instead of aggregating token representations to a single vector, it computes predictions for each token position.

The model can be used to predict masked tokens during pretraining, and the learned encoder can be transferred to downstream tasks.

Example usage:

model = RoFormerMLM(enc_num_characters=100)
trainer = L.Trainer(max_epochs=50)
trainer.fit(model=model, train_dataloaders=train_dataloader)
Parameters:

  • enc_num_characters (int) – Vocabulary size

  • enc_hidden_dim (int) – Token embedding dimensionality, defaults to 256

  • enc_expansion_dim (int) – Dimensionality inside transformer blocks, defaults to 1024

  • enc_num_heads (int) – Number of attention heads, defaults to 4

  • enc_num_layers (int) – Number of transformer blocks, defaults to 2

  • enc_attention_dropout (float) – Dropout for attention, defaults to 0.1

  • enc_hidden_dropout (float) – Dropout in dense layers, defaults to 0.1

  • pred_hidden_dims (list[int]) – Hidden dimensions for prediction head, defaults to [512]

  • pred_activation (str) – Activation function, defaults to ‘gelu’

  • pred_dropout (float) – Dropout for prediction head, defaults to 0.1

  • loss_fn (str) – Loss function to use, defaults to ‘cross_entropy’

  • loss_args (dict) – Additional arguments for loss function

  • optimizer (str) – Optimizer to use, defaults to ‘adamw’

  • optimizer_args (dict) – Additional arguments for optimizer

  • scheduler (str) – Learning rate scheduler, defaults to ‘cosine_annealing’

  • scheduler_args (dict) – Additional arguments for scheduler
