matcha.torch.models.finetuning.passthrough_predictor

Identity-only predictor for Finetuner with keep_existing_predictor=False.

When a Finetuner is asked to discard the pretrained model’s predictor, every .predictor in the self.pretrain chain — including any nested Finetuner wrappers and the leaf classic/pretraining model — is replaced with a PassthroughPredictor. The result: self.pretrain.encode(batch) chains through with identity behavior at each level, and the new pred_hidden_dims MLP consumes the leaf encoder’s output directly.

This module mirrors the role played by _StubPredictor for pure origin_type="pretraining" artifacts: both provide the minimal attribute surface (prediction_head) that Finetuner and BaseClassicModel expect. PassthroughPredictor additionally exposes .encode and .forward because BaseClassicModel.encode() dispatches through predictor.encode — using torch.nn.Identity would raise AttributeError.
