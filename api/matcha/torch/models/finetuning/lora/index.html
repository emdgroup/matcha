matcha.torch.models.finetuning.lora

Low-Rank Adaptation (LoRA) for parameter-efficient finetuning.

Implements the LoRA technique (Hu et al., arXiv:2106.09685) which decomposes weight updates into low-rank matrices, enabling efficient adaptation of large pretrained models while keeping most parameters frozen.

Low-Rank Adaptation (LoRA) wrapper around a frozen nn.Linear layer.

Decomposes the weight update into two low-rank matrices so that the original pretrained weights are kept frozen while only the small adapter matrices are trained. The effective weight becomes W' = W + (B @ A) * scaling.

References: - https://arxiv.org/abs/2106.09685

Parameters:

  • original_linear (nn.Linear) – the frozen linear layer to wrap

  • rank (int) – rank of the low-rank decomposition

  • alpha (float) – scaling numerator (scaling = alpha / rank)

Recursively replace nn.Linear layers inside module with LoRALinear wrappers.

Only targets linear layers whose both dimensions are >= min_dim so that tiny projection heads, edge-feature layers, etc. are left untouched.

Parameters:

  • module (nn.Module) – the module to modify in-place

  • rank (int) – LoRA rank

  • alpha (float) – LoRA scaling numerator

  • min_dim (int) – minimum feature dimension for a layer to be wrapped
