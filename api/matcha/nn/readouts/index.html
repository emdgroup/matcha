class matcha.nn.readouts.PyGAggregationWrapper(aggregation: torch_geometric.nn.aggr.Aggregation)[source]

Bases: torch.nn.Module

Wrapper to adapt PyG aggregation classes to the matcha readout interface.

PyG aggregations expect (x, index) while matcha readouts expect (graph, x). This wrapper handles the conversion.
