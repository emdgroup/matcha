matcha.nn.multitask.compute_task_affinity(sklearn_model: matcha.sklearn.base_sklearn_model.BaseScikitLearnModel, molecules: list, labels: numpy.ndarray, affinity_every_n_steps: int = 10, device: str | None = None) → TaskAffinityResult[source]

Compute task affinity matrix using the Task Affinity Grouping (TAG) algorithm.

Trains a single multitask model, periodically measuring how each task’s gradient step affects all other tasks’ losses. The collected affinity snapshots are averaged to produce the final matrix.

The affinity Z[i, j] measures how much a gradient update on task i affects task j’s loss. A positive affinity indicates that training on task i reduces the loss of task j.

Based on: https://arxiv.org/pdf/2109.04617

Parameters:

  • sklearn_model (matcha.sklearn.base_sklearn_model.BaseScikitLearnModel) – A fitted MATCHA sklearn model instance.

  • molecules (list) – Training molecules (RDKit Mol objects or SMILES strings).

  • labels (numpy.ndarray) – Training labels of shape (n_samples, n_tasks).

  • affinity_every_n_steps (int) – Collect affinity every N training steps.

  • device (str or None) – Device for computation ('cuda', 'cpu', or None for auto).

Returns:

Object containing the affinity matrix and helper methods.

Return type:

TaskAffinityResult

Example:

from matcha.sklearn.graph import GraphRegressor
from matcha.nn.multitask import compute_task_affinity

model = GraphRegressor(num_endpoints=4)
model.fit(train_mols, train_labels)

result = compute_task_affinity(model, train_mols, train_labels)
fig = result.plot_affinity_matrix()
fig.show()

# Get top 2 most affine tasks for task 0
top_tasks = result.get_top_k(source_task=0, k=2)
