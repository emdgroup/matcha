matcha.nn.deep_lasso.deep_lasso_regularizer(loss, inputs)[source]

Compute the Deep Lasso regularization term.

Calculates the group-lasso norm of the gradient of loss with respect to inputs, encouraging sparsity in the input-gradient space.

Parameters:

  • loss (torch.Tensor) – Scalar loss tensor (must support autograd.grad).

  • inputs (torch.Tensor) – Input tensor that loss was computed from.

Returns:

Scalar regularization value.
