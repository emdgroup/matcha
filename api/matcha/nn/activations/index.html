Bases: torch.nn.Module

GEGLU activation function.

Splits the input along the last dimension into a value half and a gate half, then returns value * GELU(gate).

Reference: https://arxiv.org/abs/2002.05202v1

Parameters:

x (torch.Tensor) – Input tensor whose last dimension is split in two.
