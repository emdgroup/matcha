E(3)-equivariant graph neural network classifier for molecular conformers.

Implements the EGNN architecture from Satorras et al., E(n) Equivariant Graph Neural Networks (arXiv:2102.09844). Learns to embed molecular conformers using equivariant message passing over 3D coordinates and predict properties in an end-to-end manner. Compatible with classification datasets only.

Inherits from BaseScikitLearnGNN3D for common training and predicting routines.

References

  • https://arxiv.org/abs/2102.09844

Example usage:

model = E3GNNClassifier()
model.fit(train_mols, train_y)
predictions = model.predict(test_mols)

Graph Transformer 3D classifier for molecular conformers.

3D extension of the Graph Transformer architecture loosely inspired by the gt-pyg implementation. Uses multi-head self-attention over 3D molecular conformers with positional encodings derived from the molecular geometry. Compatible with classification datasets only.

Inherits from BaseScikitLearnGNN3D for common training and predicting routines.

Example usage:

model = GT3DClassifier()
model.fit(train_mols, train_y)
predictions = model.predict(test_mols)
Parameters:

  • enc_atom_hidden_dim (int) – Atom feature dimensionality, defaults to 256.

  • enc_num_layers (int) – Number of transformer layers, defaults to 3.

  • enc_jk (str) – Jumping knowledge strategy, defaults to ‘last’.

  • enc_num_heads (int) – Number of attention heads, defaults to 8.

  • enc_expansion_k (int) – FFN expansion factor, defaults to 2.

  • enc_num_kernels (int) – Number of convolution kernels, defaults to 128.

  • enc_readout (str) – Aggregation strategy for molecule-level embeddings, defaults to ‘vpa’.

Graph Transformer 3D regressor for molecular conformers.

3D extension of the Graph Transformer architecture loosely inspired by the gt-pyg implementation. Uses multi-head self-attention over 3D molecular conformers with positional encodings derived from the molecular geometry. Compatible with regression datasets only.

Inherits from BaseScikitLearnGNN3D for common training and predicting routines.

Example usage:

model = GT3DRegressor()
model.fit(train_mols, train_y)
predictions = model.predict(test_mols)
