class matcha.sklearn.managers.ensemble_calibration_manager.EnsembleCalibrationManager[source]

Manages calibration for ensemble models.

Unlike UncertaintyManager (which handles MC-dropout-based uncertainty for single models), this manager works with the ensemble’s built-in variance across members as the uncertainty signal.
