class matcha.sklearn.managers.ensemble_serialization_manager.EnsembleSerializationManager[source]

Handles saving, loading, and exporting ensemble model artifacts.

Artifact layout:

<path>/
├── config/
│   ├── manifest.yaml          # Serialization version & class info
│   ├── ensemble.yaml          # Ensemble-specific params (architecture, n_models, seed, learner)
│   ├── metadata.yaml          # Model metadata
│   ├── calibration.yaml       # Calibration params (optional)
│   └── mlflow.yaml            # MLflow params (optional)
├── state/
│   └── calibrator.pkl         # Fitted calibrator object (optional)
├── model_0/                   # First member (saved by its own serialization)
│   ├── model.ckpt
│   ├── config/
│   └── state/
├── model_1/
│   └── ...
└── model_N/
    └── ...

export_to_yaml(ensemble, path: str) → None[source]

Export the ensemble configuration and parameters to a YAML file.

Uses the first model’s input args as the learner config and adds ensemble-specific fields (architecture, metadata, n_models).

Parameters:

  • ensemble – the Ensemble instance

  • path (str) – file path for the YAML output

  • params (dict) – saved ensemble parameters (structured format with ensemble, metadata, calibration keys)
