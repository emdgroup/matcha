Parameters:

  • model_instance – the sklearn model instance

  • train_set (StackDataset) – dataset to use for training

  • val_set (StackDataset) – target to tune parameters against

  • architecture_search_budget (int) – iterations for architecture search

  • architecture_grid (dict | None) – architecture parameters to tune

  • optimizer_search_budget (int) – iterations for optimizer search

  • optimizer_grid (dict | None) – optimizer parameters to tune

  • scheduler_grid (dict | None) – scheduler parameters to tune
