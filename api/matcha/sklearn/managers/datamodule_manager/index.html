class matcha.sklearn.managers.datamodule_manager.DataModuleManager[source]

Manages the Lightning DataModule lifecycle: creation, featurization, dataset assignment, and label encoding.

The underlying datamodule object is created by the concrete sklearn model subclass via create_from_factory, and from that point on the manager owns the reference and exposes a controlled interface.
