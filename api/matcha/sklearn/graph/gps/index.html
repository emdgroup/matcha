General, Powerful, Scalable Graph Transformer (GPS) classifier.

Combines local message-passing with global self-attention in a hybrid architecture for molecular property prediction. Compatible with classification datasets only.

Inherits from BaseScikitLearnGNN for graph-specific datamodule creation and collate-aware dataloading.

References:

  • Rampasek et al., Recipe for a General, Powerful, Scalable Graph Transformer https://arxiv.org/abs/2205.12454

Example usage:

model = GPSClassifier()
model.fit(train_mols, train_y)
predictions = model.predict(test_mols)
