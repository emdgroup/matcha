Graph Isomorphism Network (GIN) classifier.

Learns to embed molecular graphs and predict properties in an end-to-end manner using message-passing with injective aggregation. Compatible with classification datasets only.

Inherits from BaseScikitLearnGNN for graph-specific datamodule creation and collate-aware dataloading.

References:

  • Xu et al., How Powerful are Graph Neural Networks? https://arxiv.org/abs/1810.00826

Example usage:

model = GINClassifier()
model.fit(train_mols, train_y)
predictions = model.predict(test_mols)

Graph Isomorphism Network (GIN) regressor.

Learns to embed molecular graphs and predict continuous properties in an end-to-end manner using message-passing with injective aggregation. Compatible with regression datasets only.

Inherits from BaseScikitLearnGNN for graph-specific datamodule creation and collate-aware dataloading.

References:

  • Xu et al., How Powerful are Graph Neural Networks? https://arxiv.org/abs/1810.00826
