Base class for finetuning pretrained encoders on downstream tasks.

Unlike standard sklearn-API models that train from scratch, finetuners load a pretrained encoder (classic or pretraining-origin) and attach a new prediction head. The encoder can be frozen, fully finetuned, or adapted via LoRA depending on finetuning_strategy.

Subclasses FinetuningRegressor and FinetuningClassifier combine this base with the appropriate task mixin.

Load a pretrained model and configure the finetuning setup.

Restores the encoder and datamodule from a saved model folder, creates a new prediction head, and configures training parameters for downstream finetuning.

Parameters:

  • path_to_pretrained (str) – path to the saved pretrained model folder

  • pred_hidden_dims (list[int]) – hidden layer dimensions for the prediction head

  • task_head_dims (list[int] | None) – per-task head dimensions (multitask)

  • activation (str) – activation function name for the prediction head

  • dropout (float) – dropout rate for the prediction head

  • num_endpoints (int) – number of output endpoints (tasks)

  • loss_fn (str) – loss function name

  • loss_args (dict) – additional arguments for the loss function

  • optimizer (str) – optimizer name

  • optimizer_args (dict) – optimizer keyword arguments

  • pretrain_lr (float) – learning rate for the pretrained encoder layers

  • pretrain_decay (float) – LR decay factor for the pretrained encoder

  • scheduler (str) – learning rate scheduler name

  • scheduler_args (dict) – scheduler keyword arguments

  • finetuning_strategy (str) – one of ‘full’, ‘frozen’, or ‘lora’

  • lora_rank (int) – rank for LoRA adaptation

  • lora_alpha (float) – scaling factor for LoRA

  • lora_min_dim (int) – minimum dimension for LoRA layers

  • num_epochs (int) – number of training epochs

  • batch_size (int) – batch size for training

  • stochastic_weight_averaging (bool) – whether to apply SWA

  • early_stopping (bool) – whether to use early stopping

  • patience (int) – early stopping patience (epochs)

  • devices (int) – number of devices to use

  • accelerator (str) – hardware accelerator type

  • clip (bool) – whether to clip predictions to training range

  • label_encoder_params (dict) – label encoder configuration

  • label_transform_map (str | list[str] | dict | None) – label transform spec

  • scaler_type (str) – type of y-scaler to use

  • seed (int) – random seed for reproducibility
