matcha.cli

Command-line interface for MATCHA molecular property prediction.

Dispatches subcommands (train, evaluate, predict, autotune, etc.) to their respective modules. Each subcommand accepts a --config argument pointing to a YAML configuration file validated against Pydantic schemas in matcha.utils.schemas.cli.
