matcha.cli.prepare_sparse_dataset

CLI command for preparing sparse multi-task datasets for pretraining.

Merges multiple parquet files into a single sparse matrix (compounds x tasks), creates train/validation splits, applies standard scaling to regression tasks, and saves the result in an efficient npz + parquet format consumed by the pretrain_multitask command.
