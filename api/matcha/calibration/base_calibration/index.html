Abstract base class for calibration methods in predictive modeling.

This class provides a framework for implementing calibration techniques, including methods for fitting the model, computing uncertainty, and saving/loading calibration parameters.

Subclasses must implement fit() and compute_uncertainty(). Calibration parameters are stored in self.params and can be persisted via save_calibrator() / from_folder().
