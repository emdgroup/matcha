matcha.utils.logging.get_default_logger(name: str, logging_path: str | None = None)[source]

Create or retrieve a standard Python logger for matcha components.

Configures a logger with console output and, optionally, file output. If the logger already has handlers, it is returned as-is to avoid duplicate handler registration.

Parameters:

  • name (str) – Identifier appended to the MATCHA logger namespace.

  • logging_path (str | None) – Optional file path for log output. Directories are created if they do not exist.

Returns:

Configured logger instance.

Return type:

logging.Logger
