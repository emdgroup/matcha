matcha.utils.splitting.time_split(df: pandas.DataFrame, column_name: str | None, split_value: float | str | None = None, split_size: float | None = None) → tuple[pandas.DataFrame, pandas.DataFrame][source]

Perform a time-based or ordered split on a DataFrame.

Sorts the DataFrame by the specified column and splits it into train and test sets based on either a split value threshold or a fractional size.

Parameters:

  • df (pd.DataFrame) – The input DataFrame to split.

  • column_name (str | None) – Name of the column to sort by. If None, the DataFrame is used in its current order.

  • split_value (float | str | None) – Threshold value; rows with values >= this go to test.

  • split_size (float | None) – Fraction of data to allocate to the test set.

Returns:

A tuple of (train_df, test_df).

Return type:

tuple[pd.DataFrame, pd.DataFrame]

Raises:

ValueError – If the column is not found, column type is unsupported, split_size is not between 0 and 1, or neither split_value nor split_size is provided.

Perform a cluster-based train/test split to minimize data leakage.

Computes molecular fingerprints, reduces dimensionality with UMAP, clusters with DBSCAN, and assigns entire clusters to either train or test to prevent similar molecules from appearing in both sets.

Parameters:

  • df (pd.DataFrame) – Input DataFrame containing a SMILES column.

  • split_size (float) – Fraction of data to allocate to the test set.

  • n_neighbors (int) – Number of neighbors for UMAP.

  • min_dist (float) – Minimum distance parameter for UMAP.

  • n_components (int) – Number of UMAP embedding dimensions.

  • random_state (int) – Random seed for UMAP.

  • feature_set (str) – Fingerprint type to compute (e.g., "ecfp").

  • metric (str) – Distance metric for UMAP.

  • n_jobs (int) – Number of parallel jobs for fingerprint computation.

Returns:

A tuple of (train_df, test_df).
