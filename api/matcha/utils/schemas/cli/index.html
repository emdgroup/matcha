class matcha.utils.schemas.cli.CLISummarizeInputModel(/, **data: Any)[source]

Bases: matcha.utils.schemas.base.BaseDataModel

Top-level input schema for the summarize CLI command.

Supports two mutually exclusive input modes:

MLflow mode — supply experiment_name and mlruns_path:

experiment_name: my_experiment
mlruns_path: ./mlruns
output_path: ./outputs

Directory mode — supply root_dir; each immediate subdirectory is treated as one model run, identified by its folder name:

root_dir: ./experiment
output_path: ./outputs

output_path is shared by both modes (default: ./outputs). In MLflow mode it receives the summary files written to disk; in directory mode it additionally receives the HTML plot files.

experiment_name: str | None = None
mlruns_path: str | None = None
root_dir: str | None = None
output_path: str | None = './outputs'
statistical_test: str | None = 'non-parametric'
runs: list[str] | None = None
magic: str | None = None

class matcha.utils.schemas.cli.EncoderPretrainDataset(/, **data: Any)[source]

Bases: matcha.utils.schemas.base.BaseDataModel

Dataset config for encoder pretraining.

Supports two modes: - MLM: only train_smiles and val_smiles parquet paths are needed. - Graph pretraining: additionally requires train_y_graph, val_y_graph

(npz with key descriptors), train_y_node, val_y_node (npz files for node-level targets), and task_type = "graph".

Node-level target files (train_y_node, val_y_node) use a packed flat + offsets layout:

np.savez_compressed("node_y.npz",
                    flat=np.concatenate(list_of_arrays),
                    offsets=np.cumsum([0] + [len(a) for a in list_of_arrays]))
task_type: str
train_smiles: str
val_smiles: str
train_y_graph: str | None = None
val_y_graph: str | None = None
train_y_node: str | None = None
val_y_node: str | None = None
