class matcha.utils.schemas.torch_api.E3GNNPretrainingInputModel(/, **data: Any)[source]

Bases: matcha.utils.schemas.generic_models.PretrainingMatchaModel, matcha.utils.schemas.generic_models.GraphMixin, matcha.utils.schemas.generic_models.GraphPretrainingMixin, matcha.utils.schemas.generic_models.E3GNNMixin

Schema for the E(3)-equivariant GNN pretraining model configuration.

Combines the graph encoder surface (GraphMixin) with E3GNN-specific coordinate-update parameters (E3GNNMixin) and the graph-pretraining head configuration (GraphPretrainingMixin).

pred_hidden_dims and pred_task_head_dims are inherited from GraphMixin but unused by pretraining models — the joint node / graph heads are configured via node_head_dims / graph_head_dims / node_task_head_dims / graph_task_head_dims instead. They default to None here so pretraining callers do not need to pass them.

torch_type: Literal['e3gnn_pretraining'] = 'e3gnn_pretraining'
