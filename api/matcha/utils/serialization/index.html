matcha.utils.serialization

Serialization utilities for loading and saving data in various formats.

Supports JSON, YAML, and pickle serialization with automatic directory creation, as well as DataFrame parsing helpers for molecular data.

matcha.utils.serialization.parse_df(input_df: pandas.DataFrame, label_key: str | list, operator_key: str | None = None)[source]

Parse a DataFrame containing molecular data into components.

Extracts RDKit molecule objects, label arrays, and optional censor operator lists from a DataFrame that has an ROMol column.

Parameters:

  • input_df (pandas.DataFrame) – Input DataFrame with an ROMol column and label/operator columns.

  • label_key (str or list) – Column name substring (or list of exact column names) used to identify label columns.

  • operator_key (str or None) – Optional column name substring used to identify censor operator columns (e.g., "<", ">"). NaN values are replaced with "=".

Returns:

A tuple of (molecules, labels, operators) where molecules is a list of RDKit Mol objects, labels is a float numpy array, and operators is a list of operator strings (or None if operator_key is None).

Return type:

tuple
