class matcha.utils.registry.ClassRegistry[source]

Bases: dict[str, Type[T]]

A dictionary-based registry that maps string aliases to classes.

Provides a decorator-based interface for registering classes under one or more aliases. Lookups are case-insensitive.

register(alias: Any | Iterable[Any] | None = None)[source]

Register a class in the registry under one or more aliases.

Can be used as a decorator. If no alias is provided, the lowercase class name is used as the default key.

Parameters:

alias (Any | Iterable[Any] | None) – One or more string aliases to register the class under. If None, defaults to the lowercase class name.

Returns:

A decorator that registers the class and returns it unchanged.
