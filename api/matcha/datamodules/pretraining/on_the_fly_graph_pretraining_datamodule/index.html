matcha.datamodules.pretraining.on_the_fly_graph_pretraining_datamodule

On-the-fly DataModule variant for graph pretraining.

Delays graph featurization until batch collation time, saving memory when working with large pretraining datasets. Follows the same wrapper pattern as OnTheFlyMLMDataModule.

class matcha.datamodules.pretraining.on_the_fly_graph_pretraining_datamodule.OnTheFlyGraphPretrainingDataModule(base: matcha.datamodules.pretraining.graph_pretraining_datamodule.GraphPretrainingDataModule, num_workers: int = 0, **kwargs)[source]

Bases: lightning.LightningDataModule

DataModule that delays graph pretraining feature generation until batch time.

Wraps a GraphPretrainingDataModule and stores raw SMILES, molecule-level labels, and atom-level labels. Graph construction and featurization are performed inside the collate function when each batch is assembled, keeping memory usage low for large-scale pretraining.

Parameters:

  • base (GraphPretrainingDataModule) – base datamodule used for featurization

  • num_workers (int) – number of dataloader workers, defaults to 0
