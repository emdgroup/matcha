Dataset that stores raw SMILES and labels for on-the-fly featurization.

Used by OnTheFlyDataModule to defer feature computation to collation time rather than computing all features upfront.

Parameters:

  • smiles – list of SMILES strings

  • y – label array of shape (N, T), either a scipy.sparse matrix (sparse-mode artifacts, 0 → missing, -1 → 0 remap applied at collate) or a 2D numpy.ndarray (dense-mode artifacts, NaN = missing, 0/1 passed through as classification classes).

  • coords – optional list of N arrays, each (A_i, 3) of per-atom 3D coordinates. When set, the wrapper forwards it to the base datamodule’s generate_features(coords=...) at collation time (if the base accepts it) — otherwise it is silently dropped with a one-shot warning.

DataModule that delays feature generation until batch iteration time.

This wrapper takes any base datamodule and modifies its behavior to generate features on-the-fly during batch collation instead of upfront during setup. This can be useful for saving memory or when features need to be computed dynamically.

collate_fn(batch: list[dict]) → dict[source]

Generate features on-the-fly from batch SMILES and collate.

Converts SMILES to molecules, then produces a dense (B, T) label tensor with NaN in missing positions. The path depends on the stored label type:

  • Sparse (scipy.sparse rows): vstack + densify, then remap 0 → NaN (missing) and -1 → 0 (classification negative).

  • Dense (2D numpy.ndarray rows): stack + cast to float32; NaN already marks missing and classification values are already 0/1 — no remap is applied.

The two paths converge on the same tensor shape / dtype / missing-value convention before delegating to the base datamodule’s feature generation and collation. When batch items carry a coords field, the wrapper probes the base’s generate_features signature once (cached) and forwards coords via coords= if accepted. Otherwise coords are silently dropped and a single logging.warning is emitted so the pytest filterwarnings=error gate is not tripped.

Parameters:

batch – list of dicts with smiles, y, and optionally coords keys

Returns:

collated batch dict from the base datamodule
