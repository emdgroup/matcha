matcha.datamodules.pretraining.graph_3d_pretraining_datamodule

3D graph pretraining DataModule with user-supplied atomic coordinates.

Extends GraphPretrainingDataModule with a required coords argument supplied by the user at featurize time. Coordinates are validated against the canonical-SMILES atom count, reordered to the canonical atom ordering that GraphDataModule._calculate_graph() produces, and attached to each per-molecule torch_geometric.data.Data on pos — the PyG convention. Batch.from_data_list then auto-concatenates pos alongside x, y_node and the positional encodings, so the pretraining collate function inherited from the parent needs no changes and the encoder reads coords from graph.pos inside its per-layer hook.

ETKDG-style on-the-fly conformer generation is never performed inside this datamodule.

3D graph pretraining datamodule with user-supplied atomic coordinates.

Extends GraphPretrainingDataModule with a required coords argument supplied at featurize time. Per-molecule 3D coordinates ride on Data.pos so that torch_geometric.data.Batch auto-concatenates them alongside x, y_node and the positional encodings — the parent collate function needs no changes.

Example usage:

dm = Graph3DPretrainingDataModule()

# coords is a list of arrays, one per molecule, each of shape (num_atoms, 3)
# y_node is a list of arrays, one per molecule, each of shape (num_atoms, T)
# y_graph is a numpy array of shape (N, G)
dataset = dm.featurize(
    mol_list=mols,
    y_graph=y_graph,
    y_node=y_node,
    coords=coords,
)

All constructor parameters are inherited from GraphPretrainingDataModule.
