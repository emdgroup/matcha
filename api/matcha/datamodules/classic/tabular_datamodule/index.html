Tabular molecular representation featurization class. Allows users to convert a list of rdkit molecules and labels into a TensorDataset ready to be used for MLP-like neural network training. It uses the mnet.datamodules.rdkit_engine.Engine class for molecular fingerprints and descriptors. Common featurization logic is inherited from BaseDataModule.

The main purpose of the class is to enable the use of :method:`featurize`. Please check out :method:`featurize` for further information on the class’ usage.

Generates unscaled features for molecules and creates a StackDataset.

This method only handles feature generation without any scaling. Use featurize() for scaled features.

Parameters:

  • input_list – list of rdkit molecules to process

  • y – array (N, X) of labels, or None

  • bound_mask – list of str (N) defining whether the value is exact or is ‘less than’ / ‘more than’, will be ignored if set to None

  • n_jobs – number of cores to use when featurizing the input, if None is passed a reasonable n_jobs value will be guessed from the amount of data

featurize(input_list: list[rdkit.Chem.rdchem.Mol], y: numpy.ndarray | None = None, bound_mask: list[str] | None = None, is_training: bool = True, n_jobs: int | None = None) → torch.utils.data.StackDataset[source]

Processes a list of N molecules and a numpy array (N,X) encoding the labels into a TensorDataset, which can then be further processed for MLP-like neural network training.

This method chains the unscaled feature generation with the necessary scaling operations.

Example usage:

Parameters:

  • input_list – list of N rdkit molecules to process

  • y – array (N, X), where X is the number of classes or endpoints, or None

  • bound_mask – list of str (N) defining whether the value is exact or is ‘less than’ / ‘more than’, will be ignored if set to None

  • is_training – Whether to fit the X and Y scalers on the input, or leverage pre-existing ones to only normalize

  • n_jobs – number of cores to use when featurizing the input, if None is passed a reasonable n_jobs value will be guessed from the amount of data, defaults to None

Returns:

Processed dataset providing keys mol_features and y ready for MLP-like neural network training
