2D Graph molecular representation featurization class using PyTorch Geometric.

Allows users to convert a list of rdkit molecules and labels into a format ready to be used for graph neural network training. It uses the Chemprop featurizer backend to compute molecular graphs and converts them to PyTorch Geometric format. Common featurization logic is inherited from BaseDataModule.

The main purpose of the class is to enable the use of :method:`featurize`. Please check out :method:`featurize` for further information on the class’ usage.

Parameters:

  • laplacian_k (int) – number of components to use for the Laplacian PE embedding, defaults to 10. If set to 0, none are computed.

  • rwse_k (int) – number of steps for Random Walk Structural Encoding, defaults to 20. If set to 0, none are computed.

  • elstatic_k (int) – number of electrostatic PE components, defaults to 0.

  • distmat_k (int) – number of distance matrix PE components, defaults to 0.

  • rrwp_k (int) – number of relative random walk probability components, defaults to 20. If set to 0, none are computed.

  • compute_distances (bool) – whether to compute shortest path distances, defaults to True.

  • num_virtual_nodes (int) – number of virtual nodes to add to the graph to improve message passing, defaults to 0.

  • init_virtual_nodes (bool) – whether to initialize virtual nodes with molecular descriptors, defaults to False.

Generates a dataset ready for GNN training.

Processes a list of N molecules and a numpy array (N,X) encoding the labels into a list, which can then be further processed for graph neural network training.

This method chains the unscaled feature generation with the necessary Y scaling operations.

Example usage:

Parameters:

  • mol_list (list[Mol]) – list of N rdkit molecules to process

  • y (np.ndarray | None) – array (N, X), where X is the number of classes or endpoints

  • bound_mask (list[str] | None) – list of str (N) defining whether the value is exact or is ‘less than’ / ‘more than’, will be ignored if set to None

  • is_training (bool) – Whether to fit Y scaler on the input, or leverage a pre-existing one to only normalize

  • n_jobs (int | None) – number of cores to use when featurizing the input, if None is passed a reasonable n_jobs value will be guessed from the amount of data, defaults to None

Return StackDataset:

Processed dataset providing keys ‘graph’ and ‘y’ ready for graph neural network training
