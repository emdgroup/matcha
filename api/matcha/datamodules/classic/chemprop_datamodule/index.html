featurize(mol_list: list[rdkit.Chem.rdchem.Mol], y: numpy.ndarray | None = None, bound_mask: list[str] | None = None, is_training: bool = True, n_jobs: int | None = None) → chemprop.data.MoleculeDataset[source]

Processes a list of N molecules and a numpy array (N,X) encoding the labels into a ChemProp MoleculeDataset, which can then be further processed for ChemProp neural network training.

This method chains the unscaled feature generation with the necessary scaling operations.

Parameters:

  • mol_list – list of N rdkit molecules to process

  • y – array (N, X), where X is the number of classes or endpoints, or None

  • bound_mask – list of str (N) defining whether the value is exact or is ‘less than’ / ‘more than’, will be ignored if set to None

  • is_training – Whether to fit the X and Y scalers on the input, or leverage pre-existing ones to only normalize

  • n_jobs – number of cores to use when featurizing the input, if None is passed a reasonable n_jobs value will be guessed from the amount of data, defaults to None

Returns:

Processed MoleculeDataset ready for ChemProp neural network training
