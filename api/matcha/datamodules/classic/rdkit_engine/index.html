class matcha.datamodules.classic.rdkit_engine.Engine(n_jobs: int = 32)[source]

RDKIT descriptor and fingerprint calculation class. Each molecular representation is computed according to the parameters set in self.defaults, so that the featurization performed by a given Engine object is reproducible across datasets. The class can be instantiated directly, but in general it should be used within the TabularFeaturizer class.

Parameters:

n_jobs (int) – number of cores to use when featurizing compounds, defaults to 32
