   Graph Isomorphism Network (GIN) classifier.

   Learns to embed molecular graphs and predict properties in an end-to-end
   manner using message-passing with injective aggregation. Compatible with
   classification datasets only.

   Inherits from :class:`~matcha.sklearn.graph.BaseScikitLearnGNN` for
   graph-specific datamodule creation and collate-aware dataloading.

   References:

   - Xu et al., *How Powerful are Graph Neural Networks?*
     https://arxiv.org/abs/1810.00826

   Example usage:

   .. code-block:: python

       model = GINClassifier()
       model.fit(train_mols, train_y)
       predictions = model.predict(test_mols)

   :param int enc_num_layers: number of encoder layers for message passing,
       defaults to 3
   :param int enc_atom_hidden_dim: encoder output atom feature dimensionality,
       defaults to 256
   :param str enc_aggregation: encoder aggregation strategy for message passing,
       defaults to 'VariancePreservingAggregation'
   :param str enc_jk: encoder jumping knowledge strategy, defaults to 'last'
   :param str | None enc_norm: which norm to use inside GIN layers in the encoder,
       defaults to 'batch'
   :param str enc_readout: encoder aggregation strategy for returning molecule-level
       embeddings, defaults to 'vpa'
   :param float enc_dropout: dropout rate across the encoder, defaults to 0.2
   :param str enc_activation: activation function to use across the encoder,
       defaults to 'swish'
   :param list[int] pred_hidden_dims: shape of hidden MLP layers in the predictor,
       defaults to [256, 256]
   :param list[int] | None pred_task_head_dims: shape of the MLP layers dedicated
       to each task independently, defaults to None
   :param str pred_activation: activation function to use across the predictor,
       defaults to 'swish'
   :param float pred_dropout: dropout rate across the predictor, defaults to 0.2
   :param int num_endpoints: number of endpoints (if multitasking) or classes
       (if classification) to predict, defaults to 1
   :param str loss_fn: loss function to optimize, defaults to 'bce'
   :param dict loss_args: additional arguments for the loss function, defaults to {}
   :param str optimizer: optimizer to use while training, defaults to 'adamw'
   :param dict optimizer_args: additional arguments for the optimizer, defaults
       to {'lr': 1e-4, 'weight_decay': 1e-4}
   :param str scheduler: scheduler to change the learning rate during training,
       defaults to 'warmup_linear_decay'
   :param dict scheduler_args: additional arguments for the scheduler, defaults
       to {'min_lr': 1e-5}. If 'total_steps' is not provided, it is
       auto-computed as num_epochs * ceil(len(train_data) / batch_size).
   :param int num_epochs: number of epochs to train for, defaults to 100
   :param int batch_size: batch size to use for training and prediction, defaults
       to 64
   :param bool stochastic_weight_averaging: whether to add a few epochs with SWA
       on top of regular training, defaults to False
   :param bool early_stopping: whether to use early stopping, defaults to True
   :param int patience: how many epochs to wait before early stopping, defaults
       to 20
   :param int devices: how many devices to use for training, defaults to 1
   :param str accelerator: hardware accelerator to use for training, defaults
       to 'gpu'
   :param int rwse_k: number of random walk structural encoding dimensions,
       defaults to 0
   :param int laplacian_k: number of Laplacian positional encoding components,
       defaults to 0
   :param int elstatic_k: number of electrostatic encoding dimensions,
       defaults to 0
   :param int distmat_k: number of distance matrix encoding dimensions,
       defaults to 0
   :param int rrwp_k: number of relative random walk probability dimensions,
       defaults to 0
   :param int num_virtual_nodes: number of virtual nodes to add, defaults to 0
   :param float enc_eps: initial value of the ``eps`` term in ``GINEConv``,
       defaults to 0.0
   :param bool enc_train_eps: whether to learn ``eps`` as a parameter
       (paper-recommended GIN-ε variant), defaults to True
   :param list[str] | None feature_list: list of strings defining which molecular
       feature set to compute, defaults to None
   :param dict label_encoder_params: additional parameters for the label encoder,

   :param str | list[str] | dict | None label_transform_map: label transform
       specification, defaults to None
   :param bool augment_resonance: whether to augment with resonance structures,
       defaults to False
   :param int seed: random seed for reproducibility, defaults to 0

   Learns to embed molecular graphs and predict continuous properties in an
   end-to-end manner using message-passing with injective aggregation.
   Compatible with regression datasets only.

   Inherits from :class:`~matcha.sklearn.graph.BaseScikitLearnGNN` for
   graph-specific datamodule creation and collate-aware dataloading.
