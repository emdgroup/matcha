   E(3)-equivariant graph neural network classifier for molecular conformers.

   Implements the EGNN architecture from Satorras et al., *E(n) Equivariant
   Graph Neural Networks* (arXiv:2102.09844). Learns to embed molecular
   conformers using equivariant message passing over 3D coordinates and
   predict properties in an end-to-end manner. Compatible with classification
   datasets only.

   Inherits from :class:`~matcha.sklearn.graph3d.BaseScikitLearnGNN3D`
   for common training and predicting routines.

   .. rubric:: References

   - https://arxiv.org/abs/2102.09844

   Example usage:

   .. code-block:: python

       model = E3GNNClassifier()
       model.fit(train_mols, train_y)
       predictions = model.predict(test_mols)

       passing, defaults to 3.

       defaults to 128.

       defaults to 16.

       encoding, defaults to 4.

       defaults to False.
